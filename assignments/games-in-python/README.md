# 📘 Tarefa: Jogo da Forca

## 🎯 Objetivo

Pratique o uso de strings, listas, seleção aleatória, loops e condicionais em Python construindo uma versão jogável do clássico jogo da Forca.

## 📝 Tarefas

### 🛠️ Preparar a Palavra Secreta

#### Descrição
Escolha uma palavra aleatoriamente de uma lista predefinida e prepare uma representação oculta para que o jogador possa tentar adivinhá-la.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Exibir um espaço em branco para cada letra da palavra, como `_ _ _`.

### 🛠️ Implementar as Rodadas do Jogo

#### Descrição
Permita que o jogador tente adivinhar a palavra, revelando os acertos e acompanhando as tentativas restantes até a vitória ou o fim do jogo.

#### Requisitos
O programa concluído deve:

- Aceitar palpites de letras e revelar as posições correspondentes na palavra.
- Acompanhar e exibir o número de tentativas incorretas restantes.
- Encerrar o jogo quando a palavra for adivinhada ou as tentativas se esgotarem.
- Exibir uma mensagem de vitória ou derrota ao final do jogo.
